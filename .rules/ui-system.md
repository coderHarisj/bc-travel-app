# UI System & Responsive Rules

## Figma Extraction
When generating UI:
- Extract color palette
- Extract typography scale
- Extract spacing system
- Convert into MUI theme
- No hardcoded colors

## Responsive Rules
- Must use MUI breakpoints:
  xs, sm, md, lg, xl
- No fixed width layouts
- Use Grid system
- Forms stack vertically on sm and below
- Tables scroll horizontally on small screens
- Test at 360px, 768px, 1024px+

## Layout Rules
- No magic pixel values
- Use theme spacing
- Use theme typography

## Prohibited
- No hardcoded colors
- No fixed width layouts
- No magic pixel values
- No theme overrides without justification
